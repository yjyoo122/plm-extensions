# PLM Extensions — 설치 및 사용 안내서 (한국어)

English: [INSTALL-en.md](INSTALL-en.md) · 日本語: [INSTALL-ja.md](INSTALL-ja.md)

---

## 1. 이것은 무엇입니까

이 패키지는 고객사의 **Autodesk Fusion Manage 테넌트** 위에서 동작하는 맞춤형 웹 응용프로그램(User Experiences) 모음입니다. PLM 포털, 작업공간 탐색기(Workspace Navigator), 각종 부품표(BOM) 편집기, 대시보드, 관리자용 유틸리티가 포함되어 있습니다. **사용자 PC에서** 소형 웹 서버로 실행되며, 브라우저에서 `http://localhost:8080` 으로 접속해 사용합니다. 데이터는 Fusion Manage REST API를 통해 주고받습니다. 비용은 들지 않습니다. 임대할 서버도, 외부에 호스팅되는 서비스도 없습니다. PLM 데이터는 "사용자 PC"와 "고객사 테넌트" 사이에서만 오가며, Fusion Manage 외부에는 어떤 데이터도 저장되지 않습니다.

> 본 소프트웨어는 <ins>Autodesk 공식 제품이 아닙니다</ins>. 무보증 현상태(as is) 조건으로 제공되는 커뮤니티 소스 코드입니다. 자세한 내용은 저장소의 `README.md` 면책 조항을 참고하십시오.

## 2. 시작하기 전에

| 필요한 것 | 필요하지 않은 것 |
| -- | -- |
| 로그인 가능한 Fusion Manage 테넌트(Autodesk 계정) | 별도로 설치할 것 — 실행에 필요한 Node.js 런타임까지 패키지에 모두 들어 있습니다 |
| 테넌트의 [일반 설정]에서 클라이언트 ID를 허용 목록에 등록할 권한(또는 대신 등록해 줄 관리자) | 명령 프롬프트/터미널 사용 — 명령을 입력할 일이 없습니다 |
| Windows 11 PC와 브라우저(Chrome 또는 Edge) | 코딩 지식, `.js` 파일 직접 편집 |
| 약 **10분**의 시간 | 비용 — 여기서 사용하는 Autodesk Platform Services API는 무료입니다 |

**용어 설명**

| 용어 | 쉬운 설명 |
| -- | -- |
| **테넌트(tenant)** | 회사의 Fusion Manage 사이트를 말합니다. 로그인 주소의 맨 앞부분이며, `https://acme.autodeskplm360.net` 이라면 테넌트 이름은 `acme` 입니다. |
| **APS** | Autodesk Platform Services. 이 도구가 로그인을 수행할 수 있도록 "응용프로그램"을 등록하는 Autodesk 개발자 사이트입니다. |
| **클라이언트 ID(Client ID)** | 1단계에서 만드는 APS 응용프로그램을 식별하는 긴 문자열(예: `k7QsX2f9...`). 비밀번호가 아니며 기밀 정보도 아닙니다. |
| **콜백 URL(Callback URL)** | 로그인 후 브라우저가 되돌아오는 주소. APS 쪽과 이 도구 쪽이 **완전히 동일**해야 합니다. |
| **작업공간(Workspace)** | Fusion Manage의 데이터 영역. 항목(Items), 변경 오더, 프로젝트 등이 있습니다. |
| **콘솔 창** | 실행 시 나타나는 검은색 텍스트 창. 이 창 자체가 프로그램 본체입니다(3단계 참조). |

## 3. 1단계 — APS 응용프로그램 만들기

1. 브라우저에서 <https://aps.autodesk.com/myapps/create> 를 엽니다.
2. Fusion Manage에서 사용하는 것과 **동일한 Autodesk 계정**으로 로그인합니다.
3. [Choose an API]에서는 기본 선택 상태로 두어도 됩니다.
4. 응용프로그램 유형은 반드시 **`Desktop, Mobile, Single-Page App`** 을 선택합니다.
   이 부분이 중요합니다. "Web App"이나 "Server-to-Server"를 선택하면 이후 로그인 시 **401** 오류가 발생합니다.
5. [Name]과 [Description]은 자유롭게 입력합니다. 예: `PLM Extensions (local)`.
6. [Callback URL]에는 아래 문자열을 **한 글자도 다르지 않게** 입력합니다.

   ```
   http://localhost:8080/callback
   ```

   아래와 같은 실수가 매우 흔하므로 한 글자씩 확인하십시오.

   | 흔한 입력 실수 | 결과 |
   | -- | -- |
   | `https://localhost:8080/callback` (https) | `400 - Invalid redirect_uri` |
   | `http://localhost:8080/callback/` (끝에 슬래시) | `400 - Invalid redirect_uri` |
   | `http://127.0.0.1:8080/callback` | `400 - Invalid redirect_uri` |
   | `http://localhost:3000/callback` (포트 번호 오류) | `400 - Invalid redirect_uri` |

7. [Create app]을 클릭합니다.
8. 표시된 화면에서 **Client ID**를 복사합니다. 이 화면은 **닫지 말고 그대로 두십시오.** 2단계와 4단계에서 두 번 사용합니다.

---

## 4. 2단계 — 클라이언트 ID를 Fusion Manage 허용 목록에 등록

등록되지 않은 응용프로그램의 로그인은 테넌트가 거부합니다. 클라이언트 ID 등록은 최초 한 번만 하면 됩니다.

1. Fusion Manage 테넌트에 로그인합니다.
2. 오른쪽 위 톱니바퀴 아이콘에서 [**관리**(Administration)] → [**일반 설정**(General Settings)]을 엽니다.
3. 허용할 클라이언트 ID를 등록하는 설정 항목을 찾습니다(테넌트 버전에 따라 *Forge Client IDs* 또는 *APS Client IDs* 로 표시됩니다).
4. 1단계에서 복사한 클라이언트 ID를 붙여넣습니다. 기존 ID가 있으면 **삭제하지 말고** 줄을 바꿔 추가하십시오.
5. 저장합니다.

> 관리자 권한이 없다면 클라이언트 ID를 Fusion Manage 관리자에게 전달하여 등록을 요청하십시오. 이 작업 외에 관리자 권한이 필요한 것은 9장에 설명된 관리 유틸리티뿐입니다.

## 5. 3단계 — 압축 풀고 실행하기

1. 패키지 `.zip` 파일을 내려받습니다.
2. 마우스 오른쪽 클릭 → [**압축 풀기**]로 원하는 위치에 풉니다. **바탕 화면도 괜찮습니다.**
   가능하면 OneDrive 동기화 폴더는 피하십시오. 동기화가 실행 중인 파일을 잠글 수 있습니다.
3. 압축을 푼 폴더에서 **`Start.cmd`** 를 두 번 클릭합니다.
4. **검은색 콘솔 창**이 열리며 글자가 출력됩니다.

   > **중요:** 이 검은 창이 바로 **프로그램 본체**입니다. 오류 창도 아니고 남겨진 창도 아닙니다. 프로그램을 사용하는 동안에는 **닫지 마십시오.** 닫으면 서버가 중지되어 브라우저 탭도 동작하지 않습니다.
   >
   > 최소화하는 것은 괜찮습니다. 중지할 의도가 아니라면 창 안에서 `Ctrl` + `C` 를 누르지 마십시오.

5. 최초 실행 시에는 준비 과정 때문에 1~2분 정도 멈춘 것처럼 보일 수 있습니다. 정상입니다.
6. 기본 브라우저가 자동으로 `http://localhost:8080` 을 엽니다. 열리지 않으면 브라우저에 직접 이 주소를 입력하십시오.

이 시점에 Windows 보안 경고가 나타나면 9장 문제 해결의 SmartScreen 항목을 참고하십시오.

## 6. 4단계 — 설정 마법사

연결 설정이 비어 있는 상태로 처음 실행하면, 브라우저에는 시작 페이지 대신 **설정 마법사**(`http://localhost:8080/setup`)가 표시됩니다.

위에서부터 차례대로 입력합니다.

| 항목 | 입력 내용 |
| -- | -- |
| **테넌트** | 전체 주소가 아니라 테넌트 이름만 입력합니다. `https://acme.autodeskplm360.net` 이면 `acme`. |
| **클라이언트 ID** | 1단계에서 복사한 값을 붙여넣습니다. |
| **콜백 URL** | `http://localhost:8080/callback` 그대로 둡니다. APS 응용프로그램과 완전히 일치해야 합니다. |
| **테마** | `dark`(어둡게) 또는 `light`(밝게). 나중에 변경할 수 있으며, 개별 URL에 `&theme=light` 를 붙여 전환할 수도 있습니다. |
| **언어** | `English` / `日本語 (ja)` / `한국어 (ko)`. 사용자 인터페이스의 기본 언어가 됩니다. |

이어서 다음을 수행합니다.

1. [**작업공간 검색**(Discover workspaces)]을 클릭합니다. 마법사가 테넌트에 로그인하고(일반적인 Autodesk 로그인 창이 나타나면 승인하십시오), 테넌트의 작업공간 목록을 읽어 **작업공간 ID**(숫자)를 자동으로 채웁니다.
   * 테넌트에 없는 작업공간은 빈칸으로 남습니다. 정상적인 동작입니다.
   * 이 ID는 각 응용프로그램이 항목, 변경 오더, 프로젝트 등을 찾는 데 사용됩니다. ID가 없으면 프로그램 내 목록이 비어 있게 됩니다.
2. 결과를 확인합니다. 값을 알고 있다면 마법사에서 개별적으로 수정할 수 있습니다.
3. [**저장**]을 클릭합니다.

마법사가 입력 내용을 `environment.js` 와 `settings/custom.js` 에 기록하고, **프로그램이 스스로 재시작합니다.** 콘솔 창에 재시작 메시지가 잠깐 출력되지만 정상이므로 창을 닫지 마십시오. 몇 초 후 브라우저를 새로 고치면 기본 화면이 나타납니다.

> 테넌트, 테마, 언어 변경이나 작업공간 재검색은 언제든 `http://localhost:8080/setup` 에서 다시 실행할 수 있습니다.

## 7. 5단계 — 사용하기

* **시작 페이지 — `http://localhost:8080`**
  사용 가능한 모든 응용프로그램의 목록과 설명, 프로그램별 추가 설정 안내가 있습니다. 처음에는 여기서 시작하십시오.
* **시작 메뉴 — `http://localhost:8080/start`**
  특정 PLM 레코드를 기점으로 하지 않는 응용프로그램을 모아 놓은 실행기입니다(예를 들어 각 BOM 편집기는 항목에서 실행되므로 여기에는 표시되지 않습니다).
* 단일 레코드를 대상으로 하는 응용프로그램은 보통 Fusion Manage에서 직접 실행하거나, URL에 레코드를 지정하여 실행합니다. 자세한 내용은 시작 페이지의 프로그램별 설명을 참고하십시오.

### 나중에 언어 바꾸기

두 가지 방법 모두 즉시 반영됩니다.

1. **페이지 머리글의 언어 선택기** — `English` / `日本語` / `한국어` 중에서 선택합니다. 페이지가 한 번 새로 고쳐지고 선택 내용은 브라우저에 기억되므로, 이후 모든 응용프로그램에 적용됩니다.
2. **어떤 URL이든** 뒤에 `?uilang=ko`(한국어), `?uilang=ja`(일본어), `?uilang=en`(영어)을 붙입니다. 예:

   ```
   http://localhost:8080/start?uilang=ko
   ```

   URL에 이미 `?` 가 있으면 `&uilang=ko` 로 붙이십시오.

아직 번역되지 않은 문구는 영어로 표시됩니다. 동작에는 문제가 없으며, 언제든 `?uilang=en` 으로 영어로 되돌릴 수 있습니다.

## 8. 종료와 재시작

| 목적 | 방법 |
| -- | -- |
| **종료** | 검은색 콘솔 창을 닫거나(**×**), 창 안을 클릭한 뒤 `Ctrl` + `C` 를 누릅니다. |
| **재시작** | `Start.cmd` 를 다시 두 번 클릭합니다. |
| 화면이 멈춘 경우 | 종료 → 재시작 → 브라우저 새로 고침(`F5`). |

종료해도 데이터는 사라지지 않습니다. PC에는 아무것도 저장되지 않으며 모든 데이터는 Fusion Manage 테넌트에 있습니다.

동료가 쓸 수 있도록 PC를 켜 둘 필요도 없습니다. 이 서버는 본인 전용이며, 동료는 각자의 PC에 설치하면 됩니다.

## 9. 문제 해결

| 증상 | 원인 | 조치 |
| -- | -- | -- |
| 로그인 시 `400 - Invalid redirect_uri` | APS 응용프로그램의 **콜백 URL**과 서버가 사용하는 `redirectUri` 가 한 글자라도 다릅니다. 끝의 슬래시, `http`/`https` 차이, `localhost`/`127.0.0.1` 차이, 포트 번호 차이가 대표적입니다. | <https://aps.autodesk.com/myapps> 에서 해당 앱을 열어 콜백 URL을 `http://localhost:8080/callback` 으로 정확히 설정합니다. 이후 설정 마법사의 값도 동일한지 확인합니다. |
| 로그인 후 **401 Unauthorized** | APS 응용프로그램 유형이 잘못되었거나, 클라이언트 ID가 테넌트 허용 목록에 등록되지 않았습니다. | APS 앱 유형이 **Desktop, Mobile, Single-Page App** 인지 확인합니다(생성 후에는 유형을 바꿀 수 없으므로 잘못되었다면 새로 만듭니다). 그리고 2단계를 다시 확인합니다. |
| 로그인 화면이 계속 반복해서 나타남 | `localhost` 의 쿠키가 차단되었거나, 해당 테넌트에 접근 권한이 없는 계정으로 로그인했습니다. | `localhost` 쿠키를 허용하고, Fusion Manage에서 사용하는 계정으로 로그인합니다. |
| 콘솔에 `EADDRINUSE` / `address already in use` 표시, 페이지가 열리지 않음 | **포트 8080을 다른 프로그램이 이미 사용 중**입니다(이 프로그램의 중복 실행 또는 다른 개발 도구). | 중복으로 열려 있는 콘솔 창을 닫고 다시 시도합니다. 다른 프로그램이 계속 점유한다면, 설정 마법사에서 콜백 URL을 비어 있는 포트(예: `http://localhost:8081/callback`)로 바꾸고 **APS 응용프로그램의 콜백 URL도 동일한 값으로** 변경합니다. |
| `Start.cmd` 를 두 번 클릭할 때 "**Windows의 PC 보호**"(SmartScreen) 표시 | 내려받은 `.cmd` 파일을 Windows가 인식하지 못하기 때문입니다. | [추가 정보] → [실행]을 클릭합니다. 미리 방지하려면 압축을 풀기 전 `.zip` 파일을 오른쪽 클릭 → [속성] → [**차단 해제**] 체크 → 확인 후 압축을 푸십시오. |
| 백신이 `Start.cmd` 를 차단/삭제하거나 Windows 방화벽이 허용을 묻는 경우 | 기업용 보안 소프트웨어는 스크립트와 로컬 서버를 의심스러운 동작으로 간주할 수 있습니다. | 해당 파일을 허용하고, 방화벽에서는 **개인 네트워크**만 허용합니다. 사내 정책상 불가능하면 압축을 푼 폴더를 예외 등록해 달라고 IT 부서에 요청하십시오. |

## 10. 새 버전으로 업데이트

설정은 두 개의 파일에만 저장됩니다. 이 두 파일만 옮기면 설정이 그대로 유지됩니다.

1. 프로그램을 **종료**합니다(콘솔 창 닫기).
2. 새 `.zip` 을 내려받아 **새로운 별도 폴더**에 압축을 풉니다. 기존 폴더에 덮어쓰지 마십시오.
3. **이전** 폴더에서 다음 두 파일을 **새** 폴더로 복사하여 덮어씁니다.

   | 파일 | 내용 |
   | -- | -- |
   | `environment.js` | 테넌트, 클라이언트 ID, 콜백 URL, 테마, 언어 |
   | `settings/custom.js` | 작업공간 ID 및 기타 사용자 설정 |

   여러 테넌트를 사용한다면 `environments/` 폴더 전체와 `settings/` 에 추가한 파일도 함께 복사하십시오.
4. **새** 폴더의 `Start.cmd` 를 두 번 클릭합니다.
5. 시작 페이지가 열리는지, 응용프로그램 하나가 정상적으로 실행되는지 확인합니다.
6. 이전 폴더는 일주일 정도 남겨 두었다가 문제가 없으면 삭제합니다.

> 설정 구조가 바뀐 릴리스에서는 설정 마법사가 이를 알려 주고 `settings/custom.js` 를 다시 생성할 수 있습니다. [작업공간 검색] 재실행은 언제 해도 안전합니다.
